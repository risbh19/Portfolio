# Independent portfolio — Edition 001

An original portfolio inspired by the cream and charcoal palette, technical labels, and kinetic typography of contentarchitecture.dev. All layout, copy, SVG artwork, typographic sculpture, and project compositions in this project were created for this portfolio. No source code or assets were copied from the reference.

## Personalize

Open `dist/content.js` and replace the bracketed profile fields. Add complete `https://` social URLs, an email address, and an optional résumé URL. Project briefs, contributions, outcomes, titles, categories, and years are grouped in the same file. Replace the three concept visuals in `dist/index.html` with your real project images when ready. The portrait is deliberately a placeholder. The sample project visuals are explicitly labeled as concepts, with no invented clients, achievements, metrics, or testimonials.

The contact, résumé, and social controls show clear placeholder states until real details are provided. With real URLs and email set, they activate automatically. The page includes a responsive menu, project filters, accessible project dialogs, an interactive typographic orbit with pause/play, reduced-motion support, native expandable process notes, and keyboard focus handling.

## Run

Serve the `dist` directory using any static HTTP server. No package installation or build step is required. The site also opens directly from `dist/index.html`. The Google Fonts stylesheet is optional: system font fallbacks are included.

## Files

- `dist/index.html`: page layout and original artwork
- `dist/style.css`: layout, responsive styles, and motion
- `dist/content.js`: personal details and project content
- `dist/app.js`: navigation and interactions
- `dist/assets/mark.svg`: original favicon
